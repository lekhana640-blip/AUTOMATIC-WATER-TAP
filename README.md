The Automatic Water Tap Project is a smart, contactless water dispensing system designed to save water and improve hygiene. 

COMPONENTS USED:

•	Power Supply (6V/9V Battery or 12V Adapter)  
•	IR Sensor  
•	Control Unit (Arduino / 555 Timer)  
•	Relay Module  
•	Water Pump (DC Pump)


 WORKING PRINCIPLE:
 
1.	Hand placed near tap → IR sensor detects reflection.
2.	Control unit processes signal → activates relay.
3.	Relay powers water pump → water flows.
4.	Hand removed → sensor stops signal → relay disconnects → pump stops → water flow ceases.
   


RESULTS:

•	Fast response (<1 second).
•	Accurate detection without false triggers.
•	Reduced water wastage by 40–60% compared to manual taps.
•	Touch-free operation → improved hygiene.
•	Smooth continuous operation without overheating.



  APPLICATIONS:
  
•	Public washrooms
•	Hospitals
•	Schools & offices
•	Households
•	Can be extended into IoT-based smart home systems
